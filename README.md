## 📁 Назначение скриптов

1. **`inventory.py`** — скрипт автоматической инвентаризации аппаратного и программного обеспечения. Собирает информацию о системе, процессоре, оперативной памяти, дисках и сетевых интерфейсах, выполняет автоматический анализ конфигурации и сохраняет структурированный JSON-паспорт.
2. **`monitor.py`** — скрипт непрерывного мониторинга нагрузки (по 12 варианту: интервал 3 с, 25 замеров, пороги CPU 85% / RAM 75% / DISK 90%, с отслеживанием дополнительной метрики — количества вошедших пользователей). Записывает журнал в CSV-файл и выводит итоговую статистику (среднее и максимум).
